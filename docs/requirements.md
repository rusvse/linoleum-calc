# Требования к новой версии проекта

## Цель
Сделать новую версию калькулятора линолеума, которая сохранит текущую логику, но будет удобнее для использования, поддержки и развития.

## Что нужно улучшить

### 1. UX и интерфейс
- исправить смещение полей в строке "Проект и параметры"
- выровнять все поля в одну строку
- сделать блок "Квартиры и помещения" симметричным и удобным
- добавить заголовки колонок для помещений
- сделать интерфейс удобным на десктопе и мобильных

### 2. Структура кода
- разделить логику на модули:
  - calculator.js
  - data.js
  - storage.js
  - ui.js
- вынести интеграцию с Google Sheets в отдельный блок
- сделать код читаемым для командной работы

### 3. Расширение функционала
- поддержка нескольких материалов
- более гибкие параметры помещений
- улучшенная работа с архивом расчётов
- возможность редактировать сохранённые проекты

### 4. Надёжность
- сохранять данные автоматически
- не терять данные при обновлении страницы
- проверять корректность введённых значений
- сохранять результаты в Google Sheets

### 5. Публикация
- новый репозиторий на GitHub
- GitHub Pages для публичного доступа
- README с описанием проекта
- документация по требованиям и задачам

## Что должно получиться
- удобный калькулятор линолеума
- понятный интерфейс для повседневной работы
- структура, готовая для развития
- возможность быстро добавлять новые функции
