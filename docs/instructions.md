# Инструкция по использованию linoleum-calc

## Что делает проект
Считает линолеум для квартир и помещений, подбирает оптимальную ширину рулона, показывает результат по помещениям и сводку для заказа.

## Как пользоваться
1. Откройте главную страницу калькулятора.
2. Заполните проект и параметры:
   - название проекта
   - линолеум / артикул
   - единицы измерения
   - ширины рулонов
   - запас
   - режим подбора
3. Добавьте квартиры и помещения.
4. Введите длину и ширину помещений.
5. Нажмите «Рассчитать».
6. Посмотрите результат и сводку для заказа.
7. При необходимости выгрузите в Google таблицу.

## Что нужно знать
- Если вы выбрали миллиметры, вводите размеры в мм.
- Ширины рулонов всегда указываются в метрах через запятую.
- Запас прибавляется с каждой стороны помещения.
- Режим подбора влияет на итоговый выбор рулона.
