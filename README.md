# linoleum-calc

Система расчёта и учёта линолеума для квартир и помещений.

## Назначение
Проект предназначен для расчёта и подбора линолеума с учётом:
- нескольких квартир и помещений
- разных ширин рулонов
- минимизации стыков или отходов
- сохранения расчётов в Google Sheets
- архива и повторного использования расчётов

## Технологии
- HTML, CSS, JavaScript
- GitHub Pages
- Google Sheets
- Google Apps Script
- LocalStorage

## Структура проекта
- `index.html` — основная страница калькулятора
- `style.css` — стили интерфейса
- `app.js` — точка входа приложения
- `modules/calculator.js` — логика расчёта линолеума
- `modules/data.js` — модели данных и работа с проектами
- `modules/storage.js` — сохранение в LocalStorage
- `modules/ui.js` — отрисовка интерфейса и обработка событий
- `google-apps-script/Code.gs` — серверная часть для Google Sheets
- `docs/instructions.md` — инструкция по использованию
- `docs/requirements.md` — требования к новой версии
- `docs/tasks.md` — список задач по развитию проекта
