# Новая версия интерфейса «Линум»

В папке находятся две независимые страницы без сборки и сторонних библиотек.

## Страницы

- `index.html` — главная страница с быстрым расчётом одной комнаты.
- `calculator.html` — рабочая страница для расчёта квартир и помещений по варианту C: список квартир слева, выбранная квартира справа.

## Как открыть

1. Скачайте репозиторий через кнопку «Код» (Code) → «Скачать ZIP» (Download ZIP).
2. Распакуйте архив, не меняя структуру папки `frontend-v2`.
3. Откройте двойным щелчком `frontend-v2/index.html` или `frontend-v2/calculator.html`.

## Расчёт квартир

1. В разделе «Параметры проекта» заполните материал, цену, ширины рулонов и запас в сантиметрах.
2. Слева нажмите «+», чтобы добавить квартиру, или выберите уже созданную.
3. В рабочей области заполните номер, название, помещения и их размеры.
4. Нажмите «Рассчитать» (Calculate) в верхней панели.
5. Внизу появятся площадь помещения, площадь с запасом, подобранная ширина рулона и итоговая ориентировочная стоимость.

Дробные значения можно вводить через запятую или точку: `3,20` или `3.20`.

## Хранение данных

Квартиры и помещения сохраняются автоматически в браузере на текущем устройстве. При очистке данных браузера эти записи могут быть удалены.

## Файлы

- `index.html`, `style.css`, `app.js` — главная страница.
- `calculator.html`, `apartment-calculator.css`, `apartment-calculator.js` — расчёт квартир.
